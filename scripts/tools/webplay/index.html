Clues come from the distilled listener running in Python on this machine — LearnedListenerSpymaster, the same object the arena plays. Boards are generated at random from the full word list; the seed in the header reproduces one. Every turn the server re-extracts all 44 features for the words still standing, re-scores the shortlist, and picks the clue and number maximising expected reward under a Plackett–Luce model of the guesser. Changing the spymaster takes effect from the next clue. k=1 tiebreak: __K1__.
