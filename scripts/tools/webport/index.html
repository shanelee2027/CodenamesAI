Both spymasters are the distilled listener: a 380-tree gradient-boosted model over 44 features, run here in the browser. After every card it re-extracts all 44 features for the words still standing and re-scores every candidate clue, then picks the clue and number maximising expected reward under a Plackett–Luce model of the guesser. When that number is 1 it keeps the word it means but gives the highest raw-similarity legal clue for it, since at k=1 the only thing that matters is how obvious the link is. Verified against the Python implementation: identical feature values, identical tree output, and the same clue chosen on 97.5% of test positions.
